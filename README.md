# AI-005: бот рецептов из продуктов

Пользователь выбирает продукты кнопками или пишет их через запятую, затем выбирает категорию. Бот подбирает блюда из **UniTools World Recipes** и показывает полный рецепт прямо в Telegram. В текущем наборе 501 рецепт и 10 категорий. Специи, вода и масло считаются доступными по умолчанию. Количество продуктов пока не учитывается; при отсутствии совпадений бот предлагает изменить выбор.

Данные UniTools: [страница набора](https://theunitools.com/ru/data), лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), атрибуция «UniTools — theunitools.com». Отдельных страниц каждого блюда в наборе нет. Изображения не используются. Полный JSON (около 2,6 МБ) и токен не входят в Git и Docker-образ.

## Локальный запуск

Требуется Python 3.12 и токен собственного бота от BotFather. Новые Python-библиотеки не нужны.

```bash
python3 scripts/fetch_recipes.py
read -rs BOT_TOKEN && export BOT_TOKEN
python3 -m recipe_bot
```

Если прямое скачивание UniTools недоступно, скачайте [официальный JSON](https://theunitools.com/data/unitools-recipes-v1.json) в доступной среде и импортируйте его: `python3 scripts/fetch_recipes.py --source /путь/к/файлу.json`. Скрипт проверяет версию и структуру файла, выводит SHA-256. Токен вводите только в переменную окружения или закрытый env-файл; не добавляйте его в Git, Google Диск, Dockerfile или отчёт.

Проверки: `python3 -m unittest discover -s tests -v`.

## Docker

Сначала подготовьте файл `data/unitools-recipes-v1.json` на машине запуска. Контейнер работает от пользователя `bot` (UID 10001), поэтому каталог и JSON должны быть доступны ему на чтение. Затем:

```bash
chmod 755 data
chmod 644 data/unitools-recipes-v1.json
docker build -t ai005-recipe-bot .
docker run --rm -v "$PWD/data:/app/data:ro" --env-file .env ai005-recipe-bot
```

Создайте локальный `.env` по `.env.example`, подставив настоящий `BOT_TOKEN`. Файл игнорируется Git и может оставаться с правами `600`: Docker передаёт переменные процессу. Для остановки используйте Ctrl+C; для проверки отправьте боту `/start`, выберите продукты и категорию, затем проверьте неверный ввод. При ошибке `Permission denied: /app/data/unitools-recipes-v1.json` проверьте права каталога и файла командами выше и перезапустите контейнер.

## Устройство

- `recipe_bot/catalog.py` — загрузка JSON, нормализация и подбор.
- `recipe_bot/bot.py` — сценарий и сообщения.
- `recipe_bot/telegram.py` — обращения к Telegram Bot API.
- `scripts/fetch_recipes.py` — получение и проверка данных.

Состояние выбора хранится в памяти процесса и обнуляется после перезапуска. За один запрос выводится до пяти рецептов. В боте можно выбрать продукт кнопкой или указать точное название из набора; распространённые варианты «Яйцо/Яйца» и «Помидор/Помидоры» объединены. При изменении версии UniTools загрузчик останавливается, пока схема не будет проверена.
